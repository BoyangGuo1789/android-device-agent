# 项目目标

让拿到仓库链接的人，在自己的电脑和 Android 设备上复刻同一套基础操作能力。

## 交付范围

可配置的设备发现、AI 租约互斥、唤醒核验、ADB 控制、新证据采集、用户共享投屏、安装排查、Agent 操作约定和隔离测试。

## 成功条件

1. 新克隆不依赖开发者的用户名、固定工具目录、设备 serial 或历史业务文件。
2. 用户完成本机调试授权后，setup / doctor 能明确检查结果。
3. 真机基础验收可持锁进入桌面，获得新截图和 UI XML，结束释放锁。
4. 未持锁操作被拒，多个 AI 不同时控制同一设备，旧 token 不可继续使用。
5. 私人证据、账号与本机状态不随源码发布。

## 后续验证范围

当前代码面向 macOS / Linux；更多设备、不同系统锁屏输出、WSL2 USB / 图形会话以及具体 App 兼容性需逐项验收。新平台未验收不能标成已复刻成功。

本仓库不提供独立运行的 Android 助手、任意 App 的保证成功流程、云端设备池、模型服务或默认业务排程。加入这些能力需单独定义范围与验收。
